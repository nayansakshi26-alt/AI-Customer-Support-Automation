# AI Customer Support Automation

## Project Overview
This project automates customer support using n8n and Gemini AI. It receives customer queries, generates AI-powered responses, stores records in Google Sheets, and sends automated email replies.

## Tech Stack
- n8n
- Gemini AI
- Gmail
- Google Sheets
- JavaScript

## Features
- AI-generated customer replies
- Automatic email responses
- Google Sheets logging
- Manual review support
- Daily support summary

## Project Status
 Currently under development.
